# Telegram бот для отслеживания товаров в интернет-магазине

Этот бот отслеживает товары на сайте https://veles-lab.ru/ и отправляет уведомления в Telegram о изменениях цен и наличии товаров.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <url-репозитория>
   cd <имя-директории>
   ```

2. Запустите скрипт установки:
   ```
   ./install.sh
   ```

   Этот скрипт создаст виртуальное окружение и установит все необходимые зависимости.

3. Создайте файл `.env` на основе `.env.example` и заполните его данными:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   TELEGRAM_CHAT_ID=ваш_id_чата
   ```

## Запуск

### Ручной запуск

Для запуска бота вручную используйте команду:
```
source venv/bin/activate && python3 bot.py
```

Для запуска с подробным выводом используйте параметр -v:
```
source venv/bin/activate && python3 bot.py -v
```

### Запуск в качестве демона

Для запуска бота в качестве демона используйте скрипт daemon.sh:

1. Запустить демон:
   ```
   ./daemon.sh start
   ```

2. Остановить демон:
   ```
   ./daemon.sh stop
   ```

3. Перезапустить демон:
   ```
   ./daemon.sh restart
   ```

4. Проверить статус демона:
   ```
   ./daemon.sh status
   ```

5. Запустить демон в фоновом режиме (автоматический перезапуск при падении):
   ```
   ./daemon.sh daemon
   ```

## Файлы

- `bot.py` - основной скрипт бота
- `parser.py` - парсер товаров с сайта
- `config.py` - конфигурационный файл
- `requirements.txt` - зависимости проекта
- `install.sh` - скрипт установки зависимостей
- `daemon.sh` - скрипт управления демоном
- `.env.example` - пример файла конфигурации
- `.gitignore` - файлы, исключаемые из Git
- `README.md` - этот файл

## Логи и данные

- Логи работы бота сохраняются в файл `bot.log`
- Данные о предыдущих товарах сохраняются в файл `previous_products.txt`
- PID процесса бота сохраняется в файл `bot.pid`
